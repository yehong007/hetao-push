# 企微定时推送

通过 GitHub Actions 定时触发企微群机器人 webhook，推送图片+文字。

## 依赖
- 仓库 Secrets 里配置 `WQ_WEBHOOK` = 企微群机器人完整 webhook URL
- 6 张图放在 `images/` 目录下

## 时段表（北京时间）

| 北京时间 | UTC cron | slot | 内容 |
|---|---|---|---|
| 12:45 | `45 4 * * *` | morning | 午会起飞前图 + 午会前工作卡打卡 |
| 13:00 | `0 5 * * *` | noon-after | 午会后图 + 午会后工作卡打卡 |
| 14:00 | `0 6 * * *` | tcm | 中医图 + 老中医们，四诊望闻问切执行了吗？ |
| 18:00 | `0 10 * * *` | evening | 夕会后图 + 高峰期晚间工作卡打卡 |
| 19:15 | `15 11 * * *` | tcm | 中医图 + 老中医们，四诊望闻问切执行了吗？ |
| 22:00 | `0 14 * * *` | night | 旧晚间落地收官图 + 一天收官准备打卡，全量培养代替局部筛选 |
| 22:30 | `30 14 * * *` | night2 | pandan图 + 全量培养代替局部筛选...建立全量培养的意识 |

## 手动测试
Actions 标签页 → "企微定时推送" → Run workflow → 输入 slot 名即可单次触发。

## 修改文本/图片
- 改文字：编辑 `push_notice.py` 里的 `SLOTS` 字典
- 换图片：替换 `images/` 下对应文件名，commit 即可
